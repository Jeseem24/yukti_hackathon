# YUKTHI 2026 — AI Chiller Anomaly Detection System

- `data/` : Raw and sample datasets (kept local via .gitignore)
- `data_pipeline/` : Feature engineering, cleaning, and preparation
- `modeling/` : Energy prediction and anomaly detection models
- `backend/` : FastAPI service exposing endpoints to the UI
- `frontend/` : User dashboard
- `docs/` : Problem statement, contracts, and system design
